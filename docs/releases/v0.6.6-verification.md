## Exact release pins and checksums

After the root metadata lands, run `scripts/release_prep.py prep` for the CUDA and
Vulkan modules. It stages Go's canonical root archive under v0.6.6 in a temporary
module proxy, then builds and vets the selected backends outside the workspace.
Run `scripts/release_prep.py check --verify-sum` at the final pin commit. Standalone
module verification, source-tip CI and release checksums remain required.

The selected backends require the root version that the same commit publishes.
Public-proxy resolution of v0.6.6 is available after the root tag is published.
Publication triggers standalone tag builds. Fresh `GOWORK=off` consumers then
verify the root, CUDA and Vulkan modules through the public Go proxy and checksum
database. GitHub Release asset checks separately verify the binaries and revision.
