The root, CUDA, Vulkan and Metal modules share one release commit. The Metal source merged in [#91](https://github.com/pkieltyka/goinfer/pull/91) at `e11050f9442873725dc47e7ab66bb737a5a6ef25`. The independently reviewed native qualification used the identical source tree at `7ee8392110a2affe22ec005ef1b25f78b5060745`.

## Native Metal qualification

On November 24, 2026 an Apple M4 with 24 GiB unified memory ran macOS 27.2.1 and Go 1.27.4, darwin/arm64, with cgo disabled. The campaign used local checkpoint files and compared forced stock Metal with the resolved default on the same 2,042 prepared token IDs. Each format used five matched ABBA blocks and four stock control cells under load, thermal and swap checks.

| Checkpoint | Median paired speedup | Faster pairs |
| --- | ---: | ---: |
| Google BF16 | 1.1548× | 10/10 |
| Unsloth Q8_0 GGUF | 1.1556× | 10/10 |

Six focused native tests passed. Both formats passed CPU cosine ≥0.9999 at widths 768 and 512, exact repeats within each profile, and an untimed 8,192-token fit and parity check. Both reject 8,193 tokens with a typed error. For Q8_0 at 2,042 tokens the trace reported 4,076 stock dispatches and 604 matrix dispatches with 797,933,568 bytes allocated in either case. The final receipt records executable digests, source and measurements. Its retained payload covers source, logs, JSON, CPU vectors and vector digests. [Qualification and manifest](https://github.com/pkieltyka/goinfer/issues/86#issuecomment-7147154129)

The hardware matrix now records the qualified M4 route. The release also carries [Radeon RX 9060 XT Vulkan projection and device-loss handling](https://github.com/pkieltyka/goinfer/pull/90), the [CUDA FP16 gate epilogue](https://github.com/pkieltyka/goinfer/pull/83), and a [decoder load-time GGUF metadata guard](https://github.com/pkieltyka/goinfer/pull/87).

The exact hardware-matrix, hardware-census, parity-manifest and Hadamard refusal checks passed locally. The root canonical module archive, four matching tags and public-proxy builds are verified separately from device coverage.
