# EmbeddingGemma 2 CUDA FP16 FFN qualification

On November 22, 2026, the RTX PRO 6000 Blackwell Max-Q Workstation Edition
with driver 595.112.07 ran goinfer product commit
`e73cd96688711d1fda91cb8bba9fb5466b7fae59`. The host was a Ryzen 9 7950X.
Both arms used one Go 1.27.3 linux/amd64 executable with
`CGO_ENABLED=0 GOAMD64=v1` and `cuda eg2_combined eg2_fp16` tags, 32 logical
CPUs and GOMAXPROCS=32. Checkpoints and prepared inputs were on local disk.

The inputs are the 200 passages from [goinfer #63](https://github.com/pkieltyka/goinfer/issues/63),
in their original 13 groups, with 100,066 prepared positions. The TSV SHA-256
is `97c426da8c155b04bf0b34e270dcfa5e8cf18bfc1343e926f63e638fea6bcd22`.
The Google pack's layer-file SHA-256 is
`28a9678df941bf3eb7acca4e27ffd2fba6eef24039374d62148d705fc83b6227`.
The Unsloth Q8_0 GGUF SHA-256 is
`6f1bd4ac6c5df7444f9cca7ca36cafe6cfa34cd6f49fefb1e0b4be8143aed8bc`.

For each format, the acceptance rule set before the run was at least 9 of 10
faster pairs and median paired speedup of at least 1.05×. In each of five ABBA
blocks, A selected `cuda-eg2-combined` and B selected `cuda-eg2-fp16` on the
same explicit CUDA UUID. In a fresh process per cell, load and attach once
and check `BatchMemory` for each group. Pass the groups in order to
`EmbedIDsBatch` and sum only those wall intervals. Pair cells 1/2 and 4/3
within each block. The exclusive timing lock covered all 20 cells in each
model run. Start load ranged from 1.03 to 1.55 across both runs. Cell-start
GPU temperatures ranged from 35 to 57 °C. Process swap was zero and all cells
ran within the 6 GiB fit envelope.

The positions/s columns are arm medians. The paired ranges were
1.07492–1.07944× for Google and 1.07192–1.09070× for Q8_0. Each arm kept its
own exact output digest across all cells. The combined outputs also matched
the published-control selector's replay digest.

For both files, tracked resident weights fell from 547,139,584 to
396,144,640 bytes. Maximum estimated additional device memory for the
requested groups was 1,098,102,880 bytes in either mode. Sampled peak GPU
memory fell from 2,130 to 1,988 MiB. Peak process RSS rose from 1,850,148 to
1,998,080 KiB for Google and from 1,378,252 to 1,485,284 KiB for Q8_0.

Untimed validation used each format's own CPU vectors. On the 81-case
reference set (22 reference texts and 59 passages) and the 200-passage slice,
every 768- and renormalized 512-dimensional FP16 vector cleared 0.999 cosine
and matched its same-mode singleton by bits when packed, split, or reordered.
Across both sets the worst cosine was 0.9999998630 for Google and
0.9999994381 for Q8_0. Tiny encoder cosine cleared 0.999948 on the same GPU,
including the input where the earlier BF16 experiment missed 0.999.

These timings cover the prepared-ID encoder calls on the fixed slice. A
full pbrain sync also prepares text, maintains caches and writes the index.
